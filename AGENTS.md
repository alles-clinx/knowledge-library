# AGENTS.md

This repository is the canonical source library for Alle's ClinX Knowledge.

## Rules
1. Work category-by-category.
2. Work in batches of at most five articles.
3. English source first; translation after source review.
4. Preserve canonical IDs, slugs and taxonomy.
5. Never insert UI CSS or JavaScript into `content_html`.
6. Keep WordPress outputs under `exports/wordpress/`.
7. Validate every changed article and regenerate search index before a batch is accepted.
8. Discovery UI is crystal-minimal. Article UI is the locked Gold Standard design.
9. Article content is CC BY 4.0; Alle's ClinX brand assets and trademarks are not.
