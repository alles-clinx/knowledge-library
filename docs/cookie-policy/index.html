Cookie Policy

This Cookie Policy explains the browser technologies used by the Alle's ClinX Knowledge site and distinguishes cookies from the offline storage used by its progressive web app.

This notice covers the GitHub-hosted Knowledge site only. The shop, account, checkout, analytics, and consent systems on allesclinx.com have separate cookie requirements.
01Cookies used by this site

As of the effective date of this notice, the Knowledge site's own front-end code does not intentionally set advertising, analytics, shopping-cart, account, or marketing cookies.

A hosting platform, browser, network, or linked third-party service may still use its own technical mechanisms outside the Knowledge front-end code.

02Offline storage

The Knowledge progressive web app uses a service worker and browser Cache Storage to retain site assets and some visited content. This supports faster loading and offline access after a page has been visited.

Cache Storage is browser-managed local storage; it is not a cookie and does not by itself create a marketing profile.

03Search data

The on-site search feature works against a static Knowledge index in the browser. The current search implementation does not use a cookie to remember search terms.

04External links and embedded services

If you leave Knowledge for another website or service, that destination may set cookies or use other storage under its own policy. Review the notice on the destination service if you want to understand or change those settings.

05Managing browser data

Most browsers allow you to inspect and remove cookies, cached files, service-worker registrations, and other site data. Removing cached Knowledge data may disable offline access until you revisit the relevant pages.

06Changes to this notice

We will update this page if the Knowledge site begins using materially different storage, analytics, authentication, or consent technologies. The date below identifies the current version.
