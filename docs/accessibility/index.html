Accessibility

Alle's ClinX aims to make Knowledge usable across common devices, input methods, languages, and assistive technologies, with a restrained interface that prioritises reading and navigation.

This statement describes the current Knowledge website. It is a design and improvement commitment, not a claim that every page or linked third-party document has completed an independent accessibility audit.
01Our approach

The Knowledge interface is designed around semantic HTML, clear heading hierarchy, text-first layouts, restrained motion, readable contrast, and responsive behaviour rather than decorative interaction.

02Keyboard and focus

Interactive controls are intended to be reachable by keyboard and to expose visible focus states. Menus, search, accordion summaries, and links should remain operable without a pointing device.

03Responsive and reduced-motion support

Layouts adapt for smaller screens, and the site's styles respect the browser's reduced-motion preference where motion is used. Text and controls are designed to reflow instead of depending on a fixed desktop canvas.

04Language and reading

Knowledge supports English and Hindi content where published. Only one language is presented at a time on bilingual article experiences so the reading order remains clear and uncluttered.

05Target and testing

Our design target is to align with WCAG 2.2 Level AA principles where reasonably applicable to this static site. We use code review and responsive interaction checks as part of site QA, while recognising that automated checks cannot replace testing with real assistive technologies and users.

06Documents and external content

Some linked PDFs, third-party pages, or legacy resources may have different accessibility characteristics. If a linked resource creates a barrier, contact us with the page or document name and the format you need.

07Reporting an accessibility problem

When reporting a barrier, include the page URL, the control or content affected, the device or assistive technology if relevant, and what you were trying to accomplish. That information helps us reproduce and correct the problem.

08Ongoing improvement

Accessibility is reviewed as templates, navigation, search, and article components change. Significant updates to this statement will be recorded in the date below.
