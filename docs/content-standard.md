# Content Standard

- Work one category at a time.
- Maximum five articles per QA batch.
- English is the canonical source.
- Do not change canonical article IDs, slugs or taxonomy without a deliberate migration.
- Article body contains semantic content only: no H1, CSS, JavaScript or inline presentation styling.
- Use H2/H3 hierarchy, stable section IDs where useful, and authoritative references for technical claims.
- Avoid padding. Depth should match user intent and technical complexity.
- All WordPress records remain draft until editorial and rendering QA pass.
