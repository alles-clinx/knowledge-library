Open knowledge for professional cleaning, hygiene, chemistry, safety, equipment and facility operations.

## Status
This repository is the source library for the Alle's ClinX Knowledge project. Content is produced and reviewed category-by-category in batches of five articles.

- 13 categories
- 107 subcategories
- 317 canonical articles
- English is the canonical source language.
- Hindi translations are linked to the same canonical article identity.
- WordPress receives generated/import-ready exports; WordPress is not the source of truth.

## Repository model

- `articles/` — permanent article source records, one folder per canonical article
- `taxonomy/` — canonical IDs, categories and subcategories
- `batches/` — five-article QA/production units
- `search/` — generated lightweight search index
- `schemas/` — machine-readable data contracts
- `exports/wordpress/` — generated WordPress import files
- `docs/` — editorial, translation, design and licensing rules

## Languages
Only one language is displayed at a time in the website UI through a minimal language switch such as `English | हिन्दी`.
